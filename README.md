🧠 Prep Pulse – AI-Powered Mock Interview Platform
An AI-based mock interview SaaS platform that simulates real interview scenarios.

🚀 Features
✨ Full-stack app using Next.js and React

🤖 Integrated Gemini AI to generate interview Q&A

🔐 User authentication using Clerk

🧩 Data stored and managed using Drizzle ORM


📂 Tech Stack
Frontend: Next.js, React.js

Backend: API Routes (Next.js), Gemini AI

Auth: Clerk

Database: PostgreSQL (via Drizzle ORM)
